# Random avatar generator

This can be used to generate a random avatar, if you want to have some
distinctiveness to your profile, but don't want anything that actually
gives reference to you.

All code and outputs are machine-generated and thus CC-0.  The output
does not rely on a neural network for generation.

This project (except this readme) is machine-generated, so adjust your
expectations when reading the code.  It may be faster to
machine-generate your own version than to try to reuse this.
