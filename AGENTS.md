This is a file designed to make random avatar icons via the web.  It should have an index.html file which will later be deployed by Github Pages.  It will show a square with a color gradient anchored at two random points on the square.  Each avatar draws from a 2-hue palette so that grids of avatars do not all look "colorful": the palette scheme is chosen from seed bits 17-18 (no RNG consumed) as analogous (hues about 20-45 degrees apart, near-monochrome look), split-complement (about 150 degrees), complementary (about 160 degrees), or independent (fully random pair).  All pattern and letter colors reuse one of the two base hues with a small plus/minus 15 degree jitter, plus a rare derived accent (about 6% of colors, hueB+40); pattern colors use a wider 35-75% lightness band for contrast while the gradient stops keep the 40-70% band.  makeColor still consumes exactly 3 rand() draws and the second hue takes the slot of the old second gradient hue (exactly 1 draw), so the pattern geometry of links shared before the palette feature is unchanged (only their colors harmonize).  There is a numeric input to choose the downloaded PNG size (16 to 1024 pixels square; the on-screen preview stays a fixed comfortable size), and a button to re-do the random generation.  The random seed is kept in the URL hash so a specific avatar can be shared or bookmarked.  The seed also selects a style family drawn over the gradient: plain, geometric shapes, concentric rings, diagonal stripes, pixel grid, mirrored identicon, waves, radiating rays, Mondrian blocks, polka dots, checkerboard, spiral, or soft blobs.  A pattern selector can force one of these families; the default is Random (the family comes from the seed).  There is an optional one-character overlay drawn on top at a random position, size, tilt, and color: any single character counts (letter, digit, punctuation, or emoji; whitespace means no overlay).  The URL hash format is seed[.family][.letter] (family is the family's index in FAMILY_NAMES, one or two digits; the seed part accepts upper or lowercase hex; the letter part is lowercase alphanumeric, or any other character URL-encoded with "." itself stored as %2E so it never clashes with the separators; "seed..c" means a letter with a random family), so shared links reproduce exactly what is shown.  Adding new families must keep appending to FAMILY_NAMES so old indices never change.  Below the controls, a History panel remembers every avatar generated in the browser (persisted in localStorage, deduplicated, newest first, capped at 60): each entry is shown as a small thumbnail re-drawn deterministically from its hash string, clicking a thumbnail restores that avatar (via the URL hash), the currently shown avatar is highlighted, and a Clear button empties the list.  There is an option to download the visible image as a PNG.  This is used to make random distinct avatar icons for profiles, etc.  A dependency-free regression suite lives in tests/smoke.mjs (run with `node tests/smoke.mjs`): it exercises the hash format, URL round-trips, RNG draw-order stability, palette coherence, history, and the download path, and it should be kept green whenever the hash format, rand() draw order, or FAMILY_NAMES indices are touched.
