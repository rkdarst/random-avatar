This is a file designed to make random avatar icons via the web.  It should have an index.html file which will later be deployed by Github Pages.  It will show a square with a color gradient anchored at two random points on the square.  There is a numeric input to choose the downloaded PNG size (16 to 1024 pixels square; the on-screen preview stays a fixed comfortable size), and a button to re-do the random generation.  The random seed is kept in the URL hash so a specific avatar can be shared or bookmarked.  The seed also selects a style family drawn over the gradient: plain, geometric shapes, concentric rings, diagonal stripes, pixel grid, mirrored identicon, waves, radiating rays, Mondrian blocks, polka dots, checkerboard, spiral, or soft blobs.  A pattern selector can force one of these families; the default is Random (the family comes from the seed).  There is an optional one-character overlay (letter or digit) drawn on top at a random position, size, tilt, and color.  The URL hash format is seed[.family][.letter] (family is the family's index in FAMILY_NAMES, one or two digits; the letter part is lowercase; "seed..c" means a letter with a random family), so shared links reproduce exactly what is shown.  Adding new families must keep appending to FAMILY_NAMES so old indices never change.  There is an option to download the visible image as a PNG.  This is used to make random distinct avatar icons for profiles, etc.
