This is a file designed to make random avatar icons via the web.  It should have an index.html file which will later be deployed by Github Pages.  It will show a square with a color gradient anchored at two random points on the square.  There is a numeric input to choose the downloaded PNG size (16 to 1024 pixels square; the on-screen preview stays a fixed comfortable size), and a button to re-do the random generation.  The random seed is kept in the URL hash so a specific avatar can be shared or bookmarked.  The seed also selects a style family drawn over the gradient: plain, geometric shapes, concentric rings, diagonal stripes, pixel grid, mirrored identicon, waves, radiating rays, Mondrian blocks, polka dots, checkerboard, spiral, or soft blobs.  A pattern selector can force one of these families; the default is Random (the family comes from the seed).  There is an optional one-character overlay drawn on top at a random position, size, tilt, and color: any single character counts (letter, digit, punctuation, or emoji; whitespace means no overlay).  The URL hash format is seed[.family][.letter] (family is the family's index in FAMILY_NAMES, one or two digits; the seed part accepts upper or lowercase hex; the letter part is lowercase alphanumeric, or any other character URL-encoded with "." itself stored as %2E so it never clashes with the separators; "seed..c" means a letter with a random family), so shared links reproduce exactly what is shown.  Adding new families must keep appending to FAMILY_NAMES so old indices never change.  Below the controls, a History panel remembers every avatar generated in the browser (persisted in localStorage, deduplicated, newest first, capped at 60): each entry is shown as a small thumbnail re-drawn deterministically from its hash string, clicking a thumbnail restores that avatar (via the URL hash), the currently shown avatar is highlighted, and a Clear button empties the list.  There is an option to download the visible image as a PNG.  This is used to make random distinct avatar icons for profiles, etc.
